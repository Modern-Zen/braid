Color

Grounded in Modern Zen: stone neutrals, teal accent, Lora and Inter. Amber is the only warm color and means exactly one thing: a person has a decision to make. Never use it for warnings, highlights, or brand.

03 / The braid

How channels split, run, and rejoin.

{{ braidDemo }}

Geometry

One SVG, viewBox 1200×360 (hero) or 1000×620 (channel map). Mainline at the vertical centre. A channel is a single path: fork curve → run → rejoin curve.

Fork and rejoin are cubic Béziers whose control points sit on the horizontal, 110px either side of the bend (C x1+110 cy, x2−110 y, x2 y). Every tangent stays horizontal, so lines never kink.

Channel spacing is 22px at n=9 and widens as n falls (spread = 11(n−1)+8). The run carries a ±9px S-drift so channels read as water, not rails.

Timing

Every path gets pathLength=1; stroke-dasharray:1; stroke-dashoffset:1 and animates to 0 with hw-draw, 900ms ease-in-out.

Sequence: mainline-in at 0s · channel i at 0.5s + 0.1s·i · agent dot fades in when its channel finishes · mainline-out after the last channel, drawn 1px bolder.

Agents travel with SMIL animateMotion along the same path, 13s + 1.3s·i, spline (.45 0 .55 1), repeating. The halo breathes with hw-pulse 2.4s.

The human moment: one channel runs hw-human (stroke) and its dot hw-human-fill, a 14s loop, amber between 46–62%, then back to teal. Nothing else on the page is amber at that moment.
